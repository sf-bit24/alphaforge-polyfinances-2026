## Ecarts au modele du skill (decisions du 2026-11-14)

- **Pas d'image de conteneur.** AgentCore Runtime deploie le code en zip depuis S3 (`code_configuration`, `PYTHON_3_13`, linux/arm64) : pas de Docker, pas d'ECR, pas de GHCR, aucun identifiant AWS dans GitHub. Le contrat `images_tfvars` devient deux artefacts : `agents-package` (`infra/build/agents.zip` et `infra/build/knowledge/`) et `release-tfvars` (`deploy/release.auto.tfvars`, `release_id` = SHA court du commit, refuse tout tag mobile). `write-images-tfvars.sh` est remplace par `write-release-tfvars.sh`; `service_images` par `release_id`.
- **Interface deployee (2026-11-15)** : ECS Fargate + ALB + CloudFront (`infra/web.tf`, `web_enabled`). Image dans **ECR**, pas GHCR : ECS ne tire une image GHCR privee qu'avec un PAT personnel de longue duree, alors que le role d'execution tire d'ECR sans secret. Le job `build_web` pousse avec le role OIDC `alphaforge-github-ecr-push` (`bootstrap/github.tf`, branche `master` seulement) ; secrets `TF_VAR_REGISTRY_*` et `packages: write` toujours absents. Taches en sous-reseaux publics du VPC par defaut avec IP publique (pas de NAT), groupe de securite ouvert a l'ALB seulement. CloudFront pour le HTTPS sans domaine (le navigateur utilise `crypto.randomUUID` et `navigator.clipboard`) ; l'ALB reste joignable en HTTP pour les reponses de plus de 60 s.
- **Un seul environnement, `sandbox`**, dans le workspace existant `larpathon` (org `larpathon_2026`, Terraform 1.17.2, sans VCS, repertoire `infra`, auto-apply). `nprod.tfvars` et `prod.tfvars` supprimes. Bloc `cloud` : `workspaces { name = "larpathon" }`, comme le bloc de l'equipe.
- **Region `us-east-1`** : seule region permise par la SCP du compte Workshop Studio.
- **Pas de Landing Zone** : l'alias `alias/accelerator/kms/cloudwatch/key` n'existe pas. Les journaux Step Functions utilisent une cle du projet (`stepfunctions.tf`). Le bucket S3 a sa cle; le bucket de vecteurs (base generale publique seulement) reste en SSE-S3.
- **Bootstrap** : `infrastructure/bootstrap/` (etat local, une fois) cree le fournisseur OIDC `app.terraform.io` et le role `alphaforge-tfc-run` (PowerUserAccess + IAM limite aux roles `alphaforge-*`), assumable seulement par les runs du workspace `larpathon`.
- **Collecte asynchrone** : Step Functions lance chaque collecteur AgentCore, puis sonde son marqueur `staging/<run_id>/<role>/_done.json` (le delai d'attente des integrations SDK est plus court qu'un agent de collecte). Definition validee par l'API `ValidateStateMachineDefinition`.
- **Ephemeres desactives** (`EPHEMERAL_ENVS_ENABLED=false`).
