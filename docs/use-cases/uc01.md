# UC01 : Créer son profil d'investisseur

Simulation seulement : aucune transaction réelle, aucun conseil. Les exemples viennent de l'application déployée, relevés le 15 novembre 2026.

| | |
| --- | --- |
| Qui | L'investisseur, connecté par Amazon Cognito |
| But | Un profil complet en cinq dimensions (objectif, horizon, risque, contraintes, préférences), avec le niveau de connaissances |
| Où | Page Profil, route `POST /api/agent` |
| Agents | Runtime `profile` : questions de base (code, sans modèle), l'agent du profil, l'agent du portefeuille existant |
| Résultat | `profil.md` et ses notes dans `clients/<client_id>/`, et la Knowledge Base du client |

Déroulement :

1. L'investisseur crée un compte (code de vérification par courriel) ou se connecte. Un compte = un `client_id` = une base `clients/<client_id>/`.
2. `session.start` crée sa base dans S3 et sa propre Knowledge Base, puis le code choisit la première question.
3. Le questionnaire de base, sans modèle : niveau de connaissances et mini-quiz, objectif, horizon, tolérance et capacité de risque, contraintes, préférences, mise en situation. Le code valide et écrit chaque réponse.
4. Facultatif : il dépose son portefeuille actuel (texte, CSV, tableur, PDF, image ou JSON ; 5 fichiers de 10 Mo au plus). L'agent du portefeuille existant en extrait les positions, le code les valorise. Il confirme, ou il passe l'étape.
5. L'agent du profil pose au plus trois questions par tour, seulement sur ce qui manque. Il cherche dans la Knowledge Base générale et dans celle du client. Le code calcule la complétude.
6. Dès 70 % de complétude, l'investisseur peut s'arrêter. L'agent du profil écrit alors le profil et ses notes.

Ce qui peut arriver :

- Un message hors cadre : le Guardrail Bedrock le bloque (`guardrail_blocked`) et invite à reformuler.
- L'agent du profil indisponible : le code pose ses questions de repli.
- Le quota de 100 Knowledge Bases par compte est atteint : le questionnaire continue sans recherche dans la base du client.
- Une requête pour un autre `client_id` que celui de la session : refusée (403).

Exemple réel (profil fictif `5edbd889…`) : `session.start` crée la base et choisit la première question en 0,2 s. Quand l'investisseur répond aux trois questions de l'agent du profil, son tour (Claude Opus 5.5) dure 12,8 s et la complétude atteint 80 % pour un seuil de 70 %. Un message volontairement hors cadre est bloqué par le Guardrail en 0,35 s.
